# "WTF Ubuntu?" vs Canonical enterprise pillars

Single-page dashboard analysing the [chalmovsky.com "WTF Ubuntu?" post](https://chalmovsky.com/posts/wtf-ubuntu) and all 686 comments on [Hacker News #50337608](https://news.ycombinator.com/item?id=50337608) about the CVE-2026-98432 patch delay, mapped to Canonical's enterprise pillars (Support & SLAs, Compliance, Percorr, Data security, Scale, APIs & analytics, Audit logs, Authorization + IAM, Engineering efficiency & cost).

- **Live page:** see the GitHub Pages URL in the repo's About section.
- **Patch status:** re-verified 2026-11-12 against the Ubuntu CVE tracker/USNs, Red Hat security data, and the Debian security tracker.
- **Source:** `index.html` is self-contained (it only loads the Ubuntu font from Google Fonts).
